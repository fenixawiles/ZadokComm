# Complaint / escalation

These normally deserve a personal reply from the advisor. When a draft is
prepared anyway (assist scope set to all inquiries, or Draft anyway), it must:
1. Open by owning the specific service failure named in the message — the
   communication gap, not the product. Never blame process or volume.
2. Not invent status, progress, or reassurance. If there is no update, say so
   in the approved register.
3. Recommit to personal, direct follow-up by the advisor.
4. Stay short. Contrition reads as sincerity only when it is brief.

Never offer compensation, discounts, or exceptions.
